# Fudoshin Dojo Karate

Landing page do Fudoshin Dojo Karate, com informações sobre as aulas de Karatê Shotokan em Parobé, RS.

## Como visualizar

O projeto é estático e não precisa de instalação ou etapa de build:

1. Abra `index (1).html` diretamente no navegador; ou
2. Inicie um servidor local nesta pasta e acesse o endereço indicado por ele.

Mantenha a pasta `imagens` junto do HTML para que as imagens da página sejam carregadas corretamente.

## Estrutura

- `index (1).html` — estrutura, estilos e interações da página.
- `imagens/cardpromo.png` — imagem promocional da seção de treinos.
- `imagens/sobresenseilasie.webp` — imagem da seção “Sobre o Fudoshin Dojo”.
- `imagens/` — demais imagens e logotipos do projeto.

## Recursos

- Layout responsivo para celular e desktop.
- Cabeçalho fixo com chamada para agendar uma aula experimental pelo WhatsApp.
- Seções de apresentação, modalidades de treino, depoimentos, informações do dojo e endereço.
- Atalho flutuante para o WhatsApp e link para abrir o endereço no Google Maps.
- Animações e efeitos visuais, respeitando a preferência do sistema por movimento reduzido.

## Antes de publicar

Revise e substitua os campos indicados como `[PLACEHOLDER]` no HTML, incluindo horários das turmas, perfil do Instagram, CNPJ, identificação do sensei e depoimentos. Confira também o telefone do WhatsApp e as informações de endereço.
